Engine Version: Unreal Engine 5.8.0

# Project Overview
The player is tasked with finding three essential items to leave the cabin, but the environment degrades as they progress.

# How to Run
1. Download and extract the provided .zip file
2. Navigate to the extracted folder
3. Launch Test_Horror.exe
4. Controls: W, A, S, D to move, Mouse to look, and E to interact with objects

# Horror Direction
The core design philosophy is to strip away the player's comfort using lighting and audio

# Technical Decisions
The experience takes place in a single indoor room using Marketplace assets, focusing on atmospheric lighting rather than complex mechanics due to the tight deadline

# Known Issues
No known issues currently

# What I Would Do With More Time
If I had more time, I would make the code cleaner, more modular, and scalable. I would also refine the overall atmospheric feel by adjusting event pacing and deliberate delays to better build tension. Additionally, I would explore the feasibility of expanding the scope to include an outdoor environment rather than restricting the experience to a single room, and implement more immersive visual transitions such as a physical eye blinking effect instead of relying on standard screen fadein and fadeout
